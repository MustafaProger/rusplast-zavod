## Изменения

- Меню не закрывается от `blur` с `relatedTarget=null` при касании.
  При открытии касанием фокус принудительно не переносится.
  Клавиатура, Escape, закрытие снаружи и короткий экран поддерживаются.
- Каталог сортируется по атрибутам: материал, нагрузка, цвет, диаметр, артикул.
  Первые серии: ПВХ лёгкая, ПВХ тяжёлая, ПНД лёгкая чёрная,
  ПНД лёгкая оранжевая, внутри каждой — 16/20/25/32 мм.
  Новые товары/диаметры включаются автоматически; API читается по всем страницам.
- `coils-studio` убран из производства и страницы комплектующих.
  Композиция заменена прежними предметными изображениями серой, чёрной и
  оранжевой трубы. Уточнены актуальные цвета ПВХ/ПНД/FRHF.
- Добавлены JSON-статьи оператора, фактические даты/автор, динамический список
  блога, BlogPosting, sitemap lastmod и manifest для подтверждения публикации.

## Подтверждённые проверки

- TypeScript, build, lint, diff-check.
- SEO/UI: 17 HTML-страниц, 78 внутренних ссылок, 36 проверок расположения
  элементов на 320/390/768/1440 px, документы, каталог, настоящие 404.
- Регрессия меню на Chromium touch / WebKit iPhone: переходы, null-blur,
  клавиатура, прокрутка, смена размера экрана.
- Каталог: 117 тестовых товаров, две страницы CMS, новый диаметр 40 мм.
- На публичном HTTPS-сайте, отдельно в Chromium touch и WebKit iPhone:
  API HTTP 200, 16 товаров в требуемом порядке, касание меню и переход,
  три замещающих изображения, отсутствие горизонтального переполнения.
- 13 тестов publisher: некорректные ссылки/даты/изображения, экранированный H1,
  SHA256, повтор без сборки и дублирования, конфликт существующего slug.

Проверки браузера выполнялись в эмуляции устройств, не на физическом телефоне.
Заявки и тестовые письма не отправлялись. CMS и база при web-релизе не
пересоздавались; серверный скрипт сверяет их идентификаторы до/после.

## Оператор

Рабочая инструкция: [SEO_AUTOPUBLISH.md](../../docs/SEO_AUTOPUBLISH.md).
Конфигурация и история находятся в локальном Artel Operator.
Генерация — Codex CLI с существующей авторизацией ChatGPT, публикация —
фиксированный publisher по SSH. Условия работы: включённый Mac, работающая
служба оператора, доступ в интернет и действующая авторизация.

Предыдущая конфигурация/image каждого web-релиза сохраняются в
`/opt/hosting/backups/rusplast-web-<tag>`, готовые файлы релиза — в
`/opt/hosting/releases/rusplast-web-<tag>`.
