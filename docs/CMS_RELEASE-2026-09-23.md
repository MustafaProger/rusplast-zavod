## Artel Operator

Оператор читает актуальные данные CMS, генерирует новую фотореалистичную PNG-обложку
через встроенный imagegen с текущей авторизацией Codex и отдельно проверяет её
визуально. Неудачная генерация/проверка останавливает публикацию. Изображение
загружается в Media Library; статья публикуется через CMS. Повтор сохраняет
подготовленный выпуск и защищает ручные изменения редактора.

Проверены настоящая генерация 1536×1024, визуальная проверка и передача обложки
в рабочий контейнер с совпадением SHA256. Эта проверка не публиковала новую
статью. Временные файлы проверки удалены. Плановый выпуск остаётся на
27.09.2026, 12:00 Europe/Moscow; история запусков сохранена.
