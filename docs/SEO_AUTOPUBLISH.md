# Статьи CMS через Artel Operator

Оператор `/Users/mustafa/Desktop/artel-operator/operators/rusplast-seo.md`
создаёт одну статью раз в четыре дня через авторизованный Codex CLI на Mac.
После сна обрабатывается только актуальный выпуск; новые API-ключи не нужны.

## Контент и изображение

`node scripts/editorial-context.mjs` читает актуальные опубликованные товары,
статьи и PDF-документы через API Strapi. Локальные seed-файлы не заменяют CMS.
Временные сетевые ошибки и ответы 408/429/500/502/503/504 повторяются до трёх раз с паузами 0,5 и 1,5 секунды. Ошибка доступа или некорректный ответ останавливает чтение; недоступность CMS после повторов останавливает подготовку. Непроверенные маркетинговые описания
не являются доказательством свойств продукции; текст не должен выдумывать
сертификаты, ГОСТ/ПУЭ, безопасность, цены, наличие или производственный опыт.

Отдельная редакционная сессия проверяет новую тему и утверждения текста. На этом этапе `generated-cover` — обязательный служебный маркер: генерация и проверка изображения происходят после одобрения текста.
Затем встроенный `image_gen` Codex CLI генерирует уникальную фотореалистичную
обложку, непосредственно связанную с содержанием статьи. Запрещены вымышленные
документы, надписи, логотипы и имитация реального завода компании. Это предметная
редакционная иллюстрация. Отдельная сессия с изображением проверяет качество.
Без сгенерированного проверенного PNG публикация не выполняется.

## Контракт публикации

JSON соответствует `Article`: `publishedAt` — дата, `author` —
`Редакция РУСПЛАСТЗАВОДА`, `image` — служебный маркер `generated-cover`.
Обложка — новый PNG от 1400×800, горизонтальный, 80 КБ–30 МБ.

```sh
python3 scripts/publish-article.py --article /absolute/article.json --image /absolute/article-cover.png --validate-only
python3 scripts/publish-article.py --article /absolute/article.json --image /absolute/article-cover.png
```

Publisher проверяет структуру и PNG, затем передаёт данные по существующему SSH
в фиксированный `cms/scripts/publish-article.cjs` внутри `rusplast-cms-1`.
Файлы получают владельца UID/GID 1000 на хосте до `docker cp -a`; чтение и
очистка выполняются пользователем node. Это совместимо с `cap_drop: ALL` без
выдачи контейнеру дополнительных возможностей. SSH использует `IPQoS=none`.
Статья не выполняется как код. Приватный CMS CLI полностью декодирует PNG через
Sharp, загружает его в папку **Media Library → Блог**, создаёт черновик и публикует
запись. Папка создаётся автоматически, если её ещё нет; новые обложки не остаются
в корне Media Library.
Новые credentials и публичные права создания/изменения статей не требуются.

CMS хранит текст, связь с media и приватные поля `publicationInputSha256`,
`imageGeneration`. Поля редакционных дат — `publishedOn` и `modifiedOn`.
Сайт нормализует их в `publishedAt`/`modifiedAt`, получает публикации из CMS
и формирует HTML, sitemap и publication manifest. Пересборка web не требуется.

Последняя строка stdout — квитанция с `url`, `slug`, `documentId`, `imageId`,
`article` (нормализованная опубликованная статья), `sha256`, `inputSha256`, `release`.
`inputSha256` — канонический SHA-256 `{article: исходный JSON, imageSha256}`.
`sha256` — хеш опубликованной статьи с реальным абсолютным CMS media URL.
Квитанция выдаётся только после проверки manifest, H1 и sitemap публичного сайта;
на обновление серверного кеша отводится до 60 секунд плюс время HTTP-запросов.

## Повтор без дубликатов

Проверенный текст сохраняется до этапа изображения. При сбое повтор использует
его, а после успешной генерации — тот же PNG. Уже опубликованный выпуск с тем же
хешем проверяется без повторной публикации. Если собственная обложка оператора
от старого запуска ещё лежит в корне Media Library, повтор переносит её в **Блог**:
адрес файла и связь со статьёй сохраняются. Файл, переименованный редактором или
перенесённый им в другую папку, остаётся на месте.
Черновик, созданный вручную, или статья, изменённая
редактором, не перезаписывается автоматизацией. Несовпадение требует редакторского
разбора и завершает запуск ошибкой. `generated-articles.json` больше не служит
хранилищем новых статей.

Для работы нужны включённый Mac, служба Artel Operator, интернет, вход ChatGPT,
возможность `image_generation` в Codex CLI и SSH-доступ к серверу.
При недоступном image_gen нет скрытого перехода на сток или платный API.
